
# robot_motor — 履带机器人差速控制仿真

## 1. 项目简介

本项目是一个基于 C++ 开发的双履带机器人底盘控制仿真程序，主要用于学习和实践机器人运动控制算法及 C++ 工程开发。

项目通过模拟左右履带电机，实现独立电机控制、原地转向、差速运动学计算、速度指令转换、等比例限幅和停止控制等功能。

项目采用多文件模块化设计，使用 CMake 构建、Git 管理版本，并通过 CTest 进行自动化测试。

目前项目运行于 Windows 环境，不直接控制真实硬件。后续可将相关控制算法迁移到树莓派机器人平台。

## 2. 开发环境

- 操作系统：Windows 10
- 编程语言：C++
- 开发工具：Visual Studio Code
- 编译器：MSYS2 UCRT64 GCC
- 构建工具：CMake
- 调试工具：GDB
- 测试工具：CTest
- 版本管理：Git

## 3. 实现功能

- **电机控制**：通过 Motor 类设置、查询和停止电机。
- **速度限幅**：限制电机控制指令的取值范围。
- **双履带控制**：独立控制左右履带。
- **原地转向**：通过左右履带反向运动实现转向。
- **差速运动学**：根据机器人线速度与角速度计算左右履带速度。
- **指令转换**：将履带线速度按模拟比例系数转换为电机指令。
- **等比例限幅**：当电机指令超限时，按相同比例缩小左右指令。
- **安全停止模拟**：提供双履带停止和基于停止标志的运动指令检查。
- **自动化测试**：使用 CTest 验证主要控制功能。

## 4. 项目结构

```text
robot_motor/
├── Motor.h
├── Motor.cpp
├── DriveController.h
├── DriveController.cpp
├── main.cpp
├── test.cpp
├── CMakeLists.txt
└── README.md
```

文件说明：

- `Motor.h / Motor.cpp`：电机对象及基本控制逻辑。
- `DriveController.h / DriveController.cpp`：双履带差速运动控制。
- `main.cpp`：机器人控制演示程序。
- `test.cpp`：自动化测试程序。
- `CMakeLists.txt`：CMake 工程配置。

## 5. 构建与运行

1. 使用 VSCode 打开项目文件夹。
2. 使用 CMake Tools 配置 Debug 构建。
3. 选择 `robot_motor` 目标并构建。
4. 通过 CMake Tools 启动程序。

测试程序：

1. 构建 `robot_tests` 目标。
2. 在 CMake Tools 的测试面板运行 CTest。
3. 检查测试结果是否显示 Passed。

## 6. 示例运行结果

```text
Left Speed:20
Right Speed:20
Left Speed:0
Right Speed:0
```

程序首先设置左右履带前进指令，然后调用停止函数，将两侧电机指令归零。

## 7. 项目说明

本项目主要用于 C++ 编程与差速控制算法学习。

当前电机速度采用模拟指令值，速度转换系数尚未通过真实电机实验标定。差速运动学计算采用理想模型，未考虑履带滑移等实际因素。

软件停止功能不等同于真实机器人的硬件安全急停系统。

后续计划在树莓派平台上开展实际电机控制与硬件适配，并逐步结合 ROS 2 构建机器人软件系统。
